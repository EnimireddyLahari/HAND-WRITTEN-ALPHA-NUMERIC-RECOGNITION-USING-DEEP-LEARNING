# MNIST Multi-Digit Handwritten Recognition
### Deep Learning Web Application · TensorFlow · Flask

---

## 📌 Project Description

A full-stack web application that lets users **draw digits on a browser canvas** and instantly recognises them using a **Convolutional Neural Network (CNN)** trained on the MNIST dataset.

- Draw a single digit → get a prediction with confidence score  
- Draw multiple digits (e.g. `583`) → get each digit segmented and predicted separately

## 🧠 CNN Architecture

```
Input (28 × 28 × 1)
    │
    ▼
Conv2D(32 filters, 3×3, ReLU)
    │
MaxPooling2D(2×2)
    │
Conv2D(64 filters, 3×3, ReLU)
    │
MaxPooling2D(2×2)
    │
Flatten
    │
Dense(128, ReLU)  +  Dropout(0.3)
    │
Dense(10, Softmax)   ← one neuron per digit class (0–9)
```

**Compiler settings**

| Setting | Value |
|---|---|
| Optimizer | Adam |
| Loss | Sparse Categorical Crossentropy |
| Metric | Accuracy |
| Epochs | 5 |
| Batch size | 128 |

## ▶️ How To Run

### 1 · Install dependencies

```bash
pip install -r requirements.txt
```

### 2 · Train the model

```bash
python train_model.py
```

This will:
- Download the MNIST dataset automatically (first run only)
- Train the CNN for 5 epochs
- Save `model/digit_model.h5`
- Display training curves and save `training_curves.png`

Expected output:
```
Test Accuracy : 99.xx%
Model saved → model/digit_model.h5
```

### 3 · Start the Flask server

```bash
python app.py
```

### 4 · Open your browser

Navigate to:
```
http://127.0.0.1:5000
```

### 5 · Use the app

1. Draw one or more digits on the white canvas
2. Click **▶ Predict** (or press `Enter`)
3. The predicted digit(s) appear with individual confidence scores
4. Click **✕ Clear** (or press `Escape`) to reset the canvas

## 📊 Multi-Digit Recognition

When the user draws multiple digits (e.g. `527`), the backend:

1. Inverts the image (white digits → black background, matching MNIST format)
2. Applies a binary threshold
3. Finds external contours with OpenCV
4. Sorts contours left-to-right by x-coordinate
5. Extracts a padded ROI for each digit
6. Passes each ROI through the CNN individually
7. Concatenates the predicted digits into the final string

## 📊 Dataset

The **MNIST** (Modified National Institute of Standards and Technology) dataset contains:

- **60,000** training images
- **10,000** test images
- Each image: **28 × 28 pixels**, grayscale, labelled 0–9

The dataset is downloaded automatically by TensorFlow on first use.

## 💡 Tips
